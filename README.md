# Applied-Programming
Code for my course in scientific C++

## Repository Structure

```
exercises/
├── chapter_1/
│   ├── problem_1_1.cpp
│   └── ...
├── chapter_2/
│   ├── problem_2_1.cpp
│   └── ...
└── ... (up to chapter_10)

submissions/
```

- **exercises/** — Chapter-by-chapter exercise solutions, named `problem_<chapter>_<number>.cpp` (e.g. `exercises/chapter_2/problem_2_4.cpp`).
- **submissions/** — Final submission files.
